# 分析方法与解释边界

## 财务指标

金额统一人民币元；净资产收益率用当季净利润除期初期末净资产平均值，不年化。资产周转率与库存周转率采用当季收入/期末资产、当季成本/期末库存；这不是行业财务研究中任意平均余额口径的无条件替代。分母缺失、为0或不具支持意义时返回缺失，不制造无限值。

收入同比、成本同比和毛利率变化使用精确上年同季；环比用紧邻季度。找不到相应季度保持缺失，不能用任意上一条记录冒充。可选字段为空时保留None；公司目标不会改变计算值。

GMPS和DQI沿用本项目透明研究规则 `rules-3.0.0`。保留这一数学版本是为了可复现，并非UI宣传版本。每项观测值、阈值、方向、权重和贡献可见。覆盖率不足60%拒绝总分；覆盖率不是置信度。得分没有样本外经验校准，不输出恶化概率，不作信用评级或买卖指令。新UI不把这些规则重新包装成训练出的AI预测。

## 年内累计转单季

对收入、成本、净利润、经营现金流、销量、产量、制造费用、研发费用做同年相邻累计差；第一季度原值保留。资产/负债/库存/期末净资产保持该季度余额，期初净资产用上一期末衔接。跨年不相减；缺少同年上季度不能暗插值。成本和收入若转换出负数会触发数据校验，需要核实累计口径。原始输入basis及转换记录保留在导入暂存/正式备注链路。

## 情景计算

R'=R×(1+价格变化)×(1+销量变化)。成本由固定与变动拆分：C'=C×固定占比 + C×(1−固定占比)×(1+单位变动成本变化)×(1+销量变化)。毛利=R'−C'。不含税、资金成本、成本台阶跃迁、产品组合变化和营运资本反馈。

敏感性包含围绕基准的±5个百分点单因素变化，以及价格/变动成本二维25格变化；每个格子从相同冻结输入重新计算，不沿前一格迭代累积。贡献为正时计算收支平衡销量倍数；贡献为负或0时不伪造有限平衡点。实际干预效果不能由这些机械假设直接证明。

## 时间序列基线与验证

只接受连续、已结束季度，至少6条；缺失目标值不插补。候选是最近值、最近四季均值、上一年同季、最近六季线性趋势。对各候选使用相同训练终点的滚动一步预测，记录每折train_end、target_period、实际与预测，按MAE选择（稳定同分顺序），同时披露RMSE与WAPE；实际值绝对和为0时WAPE不生成。

未来收入/成本负预测裁剪到0，这是业务约束不是模型发现。主结果的模型选择与误差报告来自同一滚动验证，仍有选择偏乐观。新增单独的“锁定方法末段留出”：至少10个连续已结束季度时，先用不含最后两期目标的开发折选方法，冻结选择，再对最后两期做滚动预测；第一留出期真实值可成为第二期训练输入，但不重选方法。单独披露训练边界、开发MAE、留出MAE和最近值基线；不足10期不生成该评估。测试验证改变最后两期真实值不会影响开发分数、锁定方法或第一留出预测。两期样本很小，且仍为同一序列，不能冒充行业外部验证或置信水平。至少6个滚动残差才展示下一步10%–90%经验残差范围；这是小样本经验带，不是已校准80%置信区间。2–4步不直接复制一步残差区间。没有真实行业数据训练或离线深度模型，不承诺金融决策准确率。

## 证据与解释

检索为中文分词/字符片段FTS词法检索，不是向量语义检索。相关性、人工审阅、日期、字符位置和哈希是不同的属性。相反的标签只是需要核查的线索，不等同证明矛盾。

模型数值使用指标ID由系统渲染，拒绝直接在解释中硬塞无法溯源数字或陌生引用；这样降低伪造指标风险，但不能证明自然语言推论成立。模型角色之间的反证只是辅助审阅，不把多数一致当真值。正式结论仍需财报原文、数据口径与领域人员复核。
