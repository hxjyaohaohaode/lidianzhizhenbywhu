# 本轮升级与边界

|要求|新增实际实现|边界|
|---|---|---|
|非刻板Agent|受约束动态DAG、真实并行/依赖、按输入追加工具、可选模型重规划|不是无限制自主代理，无任意URL/代码/业务写权限|
|多角色协作|5类可选模型职责、按角色供应商绑定、真实请求记录|角色数量不是独立模型数量，同模型不当独立共识|
|自迭代|结构门禁驱动有界修订；人工验收驱动策略提出/回放/激活/回滚|不是模型权重训练、自动代码部署或实证更准|
|稳定性与兜底|安全暂停/恢复、哈希断点、未知外部结果不重发、预算/授权/队列限制|不保证远端停止计费，不是分布式执行器|
|建模融入协同|同一快照上的规则、预测、固定变动成本情景、反向证据和缺口|不凭空补数据/假设，非校准金融风险模型|
|预测验证|开发折锁定方法后最后两期留出、与最近值基线比较|小样本同序列检查，不是外部行业基准|
|原品牌|原PNG与原MP4逐字节恢复、兼容旧资源路径与Range|视频播放需客户端支持；失败不阻塞工作|
|动态前端|真实DAG图/清单/缩放/键盘详情、SSE与读轮询降级、在途终态补读、销毁订阅；桌面导航收缩、移动抽屉|2026-09-27 Windows 原生 Chromium 本机流程通过；其他设备仍需验证|
|智能前台|实际任务图、报告复盘、人工验收、策略实验室；助手返回输入血缘、季度轨迹、质量警告、企业范围资料候选和对应工作流|本地助手不冒充默认已调用LLM聊天；资料候选不自动证明结论|
|同一账户多视角|企业、投资、财务分析、顾问视角可切换；按视角提供追问并匹配已批准记忆|视角是服务偏好，不提升读取或写入权限|
|多重服务身份|同一账户分别保存目标、企业范围、研究深度、输出方式、外发上限；会话和提案按身份隔离|服务身份不等于组织成员授权；切换身份不能跨账户读写|
|可审阅的研究助手|持久多轮会话、真实本地工具回执、公式与季度轨迹；研究/行动/跟踪/记忆提案先预览再确认|无密钥只执行本地工具；外部模型结果与本地规则结果明确区分|
|私有模型连接与主动跟踪|账户私有加密连接、改目标重新提交密钥；本地定期检查已存指标、按修订去重提醒|不是云端持续监控；真实供应商兼容性和费用需用户自行验证|
|体验完整性|减少动效、开场跳过/重播、主题、移动端、焦点/草稿保护、身份迟到响应隔离|未覆盖所有浏览器/设备/长期负载|
|全链路检验|实际Uvicorn/TCP/SQLite/SSE/强制退出重启/备份；Windows 原生浏览器和显式 DOM/API 桥接分别执行|未验证真实供应商、Docker、公网安全、长期负载|

保留前轮导入、修订、证据审阅、个人偏好、批准记忆、报告差异、行动状态、数据对照等业务。没有重新加入运行时样例或随机指标。旧无execution字段的计划走兼容路径，不伪装新断点功能；获奖原TypeScript API和数据库不无损兼容。
