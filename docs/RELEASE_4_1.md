# 4.1 研究工作台升级

日期：2026-09-30。源码基线为 GitHub main 的 cdca005。升级沿用既有财务计算、证据库及所有工作区，不替换原始 Logo/开场视频，不创建运行时示例企业。完整执行结果与当前限制见 [VALIDATION.md](VALIDATION.md)。

## 真实行为改进

- **连续研究**：本地核查与外部模型解释分开呈现，工具回执、公式、季度、数据修订和证据出处可追溯；外部研判先生成批准计划。切换身份/企业、关闭窗口或发起新请求后，旧响应不得重新打开窗口、覆盖新会话或恢复过期提案。
- **可用的空间布局**：桌面导航收起释放实际工作区宽度；移动抽屉隐藏时不可被键盘误进入，开关、遮罩与焦点同步；助手独立显示与调宽。工作区按研究流程组织，空数据状态指向真实下一步。
- **一致的身份约束**：服务身份控制研究目标、企业范围和外发上限；Agent 表单与助手使用一致的范围和默认设置。它是同一账户内的服务视角，不是组织成员权限或多租户角色授权。
- **写入安全**：业务删除、归档与计划取消绑定用户已查看的版本；并发修改后拒绝旧确认。连接管理重新核对当前登录会话及口令状态，旧口令校验结果不能穿过并发凭据撤销继续写入。
- **有界执行**：私有模型选择必须带账户范围；外发前验证批准计划及冻结输入；完成断点不可覆盖，恢复核对事件链与产物锚点。旧式无批准计划的外部执行请求降级为本地结果，不产生新账单；未知外部调用结果不会在重启后重发。
- **可复查的演进**：只用同意本地回放的人工验收完成案例，实际执行本地能力并记录输出状态/哈希；缺证据的空节点不算效果改善。显式研究深度和情景假设保留，当前案例/候选/基线门槛未通过时禁止激活。
- **受限跟踪**：只检查本机已存企业数据，按输入/规则修订去重；开放或未来季度不被当成已完成数据。规则有明确停用/结束边界，服务关闭期间不假称持续监控。
- **恢复与导出**：账户导出和工作区导出取同一事务快照，包含会话、提案、身份、行动、策略、数据修订和执行证据，并有分段数量/哈希。导出不含登录凭据、密码哈希或模型密文，不能冒充可直接恢复的数据库。SQLite 备份选择包含密钥时实际检查它能解密副本中的凭据；不匹配则清理未完成输出并报错。

## 15个工作区的实现与验收边界

以下“自动化”是对应后端/前端逻辑与协议测试，不等于本轮原生浏览器已经通过。当前环境 Chromium 进程因 socket 权限被终止，所有本轮屏幕/设备验收仍需 GitHub CI 或允许浏览器的本机完成。

|工作区|真实数据路径与主要行为|自动化/逆向覆盖|
|---|---|---|
|工作简报|已保存企业、执行和核查事项 → 依据/行动|空工作区、跨账户、无数据不造指标|
|研究助手|持久会话 → 工具核查 → 提案 → 明确确认|会话版本、重复请求、旧上下文响应隔离、证据范围|
|Agent 协同|预览指纹 → 批准 → 依赖图 → 冻结报告|身份/预算/所有权、前置授权、断点篡改、重启未知结果|
|数学实验|同一数据修订 → 预测/情景 → 可复查产物|单位/单季累计、缺口/零分母、显式假设、开发/留出防泄漏|
|策略演进|人工验收 → 同意案例 → 本地回放 → 批准激活/回滚|案例去重、终态、真实输出、基线变化、原始深度保留|
|数据|导入预览 → 口径确认 → 修订/恢复|暂存不写正式库、所有权、CAS、旧版本删除拒绝|
|证据|录入/获取 → 企业范围和人工立场 → 检索|外部内容不赋权限、XSS/SSRF边界、撤回后未来不再召回|
|对照|共同季度同口径企业对照|无共同季度拒绝、跨账户拒绝、不是行业排名|
|报告|真实执行结果/指标血缘/引用/评阅|不可变快照、事件锚点、伪造引用和数值门禁|
|跟踪|本地指标规则 → 检查回执 → 提醒核对|未知/陈旧/未完成季度、版本去重、取消/过期|
|行动|来源/验收标准 → 有界状态流转|完成需说明、数据/报告所有权、并发和旧确认保护|
|记忆|明确批准/身份范围/时效 → 后续召回|未批准不召回、外发快照、撤回/跨身份/并发|
|身份与连接|独立服务上下文、私有加密连接、登录会话管理|私有密钥不回显、目的地变更、旧口令/撤销竞态|
|执行记录|持久状态/工具产物/SSE/诊断|终态竞态、断线只读退避、单调事件、强制退出恢复|
|偏好与设置|账户偏好、企业目标、完整数据导出|版本冲突、密钥排除、备份密钥配对、密码/账户并发|

## 四家模型与收费边界

不增加 OpenAI 供应商。DeepSeek、GLM、Qwen 原有环境变量和私有连接继续有效；新增 `MIMO_API_KEY` 与 `MIMO_MODEL`。所有请求保持有界、非流式的结构化 JSON 解释合同；这不是任意工具调用代理。

|供应商|默认公共目标|兼容性说明|
|---|---|---|
|DeepSeek|api.deepseek.com /v1/chat/completions|保留原 deepseek-chat 配置兼容；新模型ID由用户在官方控制台核实并配置，禁止后台无提示替换|
|智谱 GLM|open.bigmodel.cn /api/paas/v4/chat/completions|区分成功文本、截断/拒绝/业务错误；HTTP429不证明仅为可重试限流|
|阿里 Qwen|dashscope.aliyuncs.com /compatible-mode/v1/chat/completions|环境默认中国大陆端点；其他地域/计划须建立明确的私有连接，不自动切区/换付费计划|
|小米 MiMo|api.xiaomimimo.com /v1/chat/completions|MiMo模型ID可配置；受限JSON流程明确关闭thinking并设置完成token上限，不伪造或回传隐藏推理|

“已配置”只表示存在配置，不等于连通、额度充足或效果验证。消费端清言/通义/MiMo会员不等于开放平台API额度。无密钥时本地工具照常工作；没有进行真实供应商请求或费用消耗。平台模型更名/下线时需核对账号当前可用清单。

官方合同查阅日期2026-09-30：[DeepSeek](https://api-docs.deepseek.com/)、[GLM接口](https://docs.bigmodel.cn/cn/api/introduction)、[GLM错误码](https://docs.bigmodel.cn/cn/faq/api-code)、[Qwen地域与Base URL](https://www.alibabacloud.com/help/en/model-studio/base-url)、[MiMo接口](https://mimo.mi.com/docs/en-US/api/chat)、[MiMo可用模型](https://mimo.mi.com/docs/en-US/api/model/list-models)。文档核对不是账号实测。

## 更新与兼容

1. 停止旧服务，使用 `scripts/backup.py` 备份数据库；若需要恢复私有连接，明确选择包含匹配主密钥并加密保管
2. 保留 `.runtime`、原 `credentials.key`、`.env` 和自己的资料；不要以源码包替换这些目录
3. 4.1 沿用数据库v3，不重算历史报告、不替换原数学公式；更高数据库版本继续拒绝降级写入
4. 编译前端随源码更新，勿混用旧JS。旧自建API客户端删除/归档/取消时需传已查看版本；不传会收到428，冲突收到409，须重新查看并确认，不能后台获取最新版本绕过确认
5. 批量删除会话须为每个ID传 `versions` 映射；账号数据导出v4保留旧核心 `data`，工作区导出保留旧 `objects`、`adaptive` 等键并增加完整快照/清单
6. 老式无批准指纹的待执行外部请求不会自动付费执行；请重新预览并批准现代计划。已完成历史结果不修改
