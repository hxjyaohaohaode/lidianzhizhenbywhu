## 用户流程与保护

- 已保存列表及详情提供清理入口；确认页列明对象名称、ID、共同季度、版本和不可撤销影响，要求明确勾选。
- 清理按记录进行处理中防重，发送已查看的 `identity_id` 与 `version`；不在冲突后自动读取新版本并删除。
- 失败保留当前记录供核对。成功移除可用列表与未提交选择；更晚的页面、身份、企业或弹窗交互不能被旧删除回调覆盖。
- 原企业、实验及历史报告冻结内容不删改。新研究与未派发步骤仍由原来源检查阻止；历史助手显示原始数学值及删除来源提示。
- 容量为同账户全部身份合计 200 份，不是每个可见筛选列表 200 份；清理原记录释放容量。
- 失效范围对照仍占容量，因此账户历史只读核查另提供独立的原对照清理。仅 `comparison` 类型有此入口，复用既有 owner/原身份/version 删除合同，不恢复历史研究或编辑权，也不新增管理员能力。
