## 2026-09-30 第三轮新增

- 问题范围：未知主题不补默认指标；年度/多季度/缺失季度澄清；历史季度金额/同环比/输入路径/趋势一致；Agent批准后仍使用同一财务前缀
- 数学联动：真实情景输出/公式/限制进入模型上下文；数学引用逐调用核对；预算删细节即无引用权限；零值保留；空值不可伪造引用
- 复盘：原季度核查日期冻结；季度切换不改变历史计算哈希；不改旧报告；实际规则组件/净资产/基期缺口进入计划
- UI/导出：保存的数值、单位、期间与哈希可读；旧解释没有数学引用仍可显示；不信任模型数字或未转义标签
- 原生脚本新增三组流程尚须当前提交CI执行；本地源代码/前端单测不是原生浏览器验收


## 2026-09-30 持续使用与恢复新增

- 迁移：三个独立版本预检、四个扩展故障注入、旧库逐项不变、新库无部分表、连接关闭、保存点回滚及真实子进程中断
- 历史修订：坏哈希/内容/结构/JSON/单位拒绝、所有权优先、竞争恢复仅一次成功、来源审计、旧报告不变
- 备份：完整快照外键、WAL包含、源库并发变化、目标及配套文件/链接不覆盖、匹配主密钥、失败清理和不泄漏
- 凭据恢复：新旧执行器缺失/坏格式/不匹配/读取失败均保留本地报告，外发及调用台账为零
- 持续整理：证据和会话删除清理当前子记录，错版本/错账户拒绝；旧孤立记录保留导出，不占有效父记录额度
- 协议恢复：全新DATA_DIR的真实Uvicorn重启、两个原账户重新登录、冻结源记录/报告/事件链一致、跨账户拒绝、副本恢复不改原库

## 2026-10-01 取消与实时读取新增

- 真正传输生命周期：取消/超时后的 DNS、待执行线程、迟到连接、TLS、头/体读取；尚未退出的工作线程继续占容量，退出后才能复用
- 真正发送前授权：新旧执行器的身份删除/权限收回/密钥旋转/连接删除；复制配置不串联并发运行，回调异常在可能发送后保留未知结果
