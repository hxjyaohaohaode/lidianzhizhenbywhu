# 币种与比较基期边界（2026-10-05）

隔离的真实 API 复现显示，明确询问美元/欧元金额仍会收到人民币事实；英文QoQ和
quarter-over-quarter请求却使用同比基期。前者没有发生真实汇率换算，后者也不是
公式计算错误，而是把用户的问题解释成了另一种范围。

新问题现在对已列明的外币表达明确拒绝财务事实、预测和新计划执行，不以人民币
代答，不新增汇率服务。人民币/CNY/RMB/元/yuan保持原行为。拒绝词表是有限规则：
USD、EUR、GBP、JPY、HKD、CAD、AUD、CHF、SGD、KRW，源码列出的对应中文名称，
dollar(s)、euro(s)、yen、British pound(s)、Swiss franc(s)、Korean won，以及$、€、£。
英文词采用边界匹配；不是任意币种或任意语言理解。含糊的¥、单独pound/sterling等
不在本轮识别集内，不能把这个有限回归称为所有外币请求的保证。

QoQ/YoY、quarter over quarter/year over year以及对应连字符写法，在基期选择、
收入增长率识别和追问继承中使用同一规则。明确同时要求两个基期时仍需澄清。
缺少指定基期时保持缺失，不退回另一个年份或季度；财务公式不变。

金融概览意图不依赖调用方是否提供默认指标列表。独立复核曾发现“美元经营概览及证据”
在助手中被拒绝，却能从直接计划或来源提案执行人民币分析；这三个真实新建路径的
反例已修正，批准均409且无新执行记录。真正不要求财务输出的币种资料查询仍可使用，
不能把“证据”一词变成绕开金融概览边界的方式。

## 历史兼容限制

旧答复和已保存范围不自动迁移、改写或重新解释。真实旧版本创建的草稿与已批准计划
也仍可能保留原来的USD/同比解释并执行；本次没有追溯使这些旧计划失效。
因此，本轮通过范围是新问题和新计划创建，不能外推为所有历史执行已采用新规则。
这个兼容性边界仍需在完整交付判断中单独处理，完整产品不因此获得合并推荐。
