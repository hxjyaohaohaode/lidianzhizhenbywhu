# 自主协同与策略演进协议

## 可改变与不可改变

自主不是绕过权限。当前实现允许在一次批准的输入与预算边界内改变工具组合、研究重点、专家路由与依赖顺序，追加缺口/反向证据/预测检查，针对结构门禁失败作有限修订。没有任意工具发现、无限循环、自我部署或自动模型训练。

能力目录：quality、quant、evidence、counterevidence、gaps、forecast、sensitivity、context、planner、analyst、researcher、challenger、revision、review、reflection、report。planner/analyst/researcher/challenger/revision是5种模型职责，其他11种为本地工具。一次任务不必全部选中，也不代表存在16个LLM。

无模型：按问题意图、显式选择、深度、数据质量和当前本地策略编排。启用模型规划后，PlannerProposal只允许限定focus、specialists和execution_order；未知字段、角色、重复项及工具拒绝，不将它解析为代码。模型请求forecast仍需连续已结束季度和目标字段；数据不足留下blocked产物。情景必须有明确用户假设，不从模型文字猜参数。

## 分工与调用

角色可分别绑定服务端配置的模型。经营解释与资料研究可并行，也可先证据后解释/先解释后资料；反证审阅在依赖完成后执行。同一模型不同提示词只是角色协作，不当作独立意见。引用检查只验证结构、有效指标、发送过的证据及数值合同，不证明语义因果正确。

批准次数预算涵盖规划、各专家、修订和候补尝试，最多8次；默认不开模型规划与跨供应商候补。只在明确429且候补提前授权时尝试其他模型；超时/连接错误/已发送但结果不明不自动重试。当前没有可靠货币费用估计，界面展示字符与真实返回token，不能把次数上限当费用封顶。

修订最多2轮。未知引用、非法数字、标记等交给已批准修订职责；纯重复解释本地删除，不增加付费调用。回退不等于成功：无模型或格式错误、引用被拒、预算不足、资料缺失、预测不适用等保留具体状态。报告包含本地反思清单、模型实际调用和未解决问题，不通过“自我评分优秀”抹去缺陷。

## 持久执行

控制状态有active、pause_requested、paused；兼容运行状态仍为queued/running/interrupted/终态。暂停只承诺下一安全批次边界，已经外发的请求不能撤回。中断任务不会自动重做：用户显式继续后复核快照、断点、产物与事件。

已完成节点一致则复用；本地未完成步骤可只读重算；外部已开始而完成记录缺失则标为unknown，不再次扣预算发请求。要重新尝试需要创建新批准计划。图重排与控制请求均写事件；并发控制使用版本检查；队列满时继续操作拒绝而非暗中增加并发。

## 策略实验室

每份实际报告可写人工验收：useful/needs_revision/rejected、说明、预期能力、是否允许本地回放。只有有报告、明确同意且有人工能力要求的记录进入案例库。修改/撤回授权或删除报告会影响新评估与激活门禁。

“从验收提出策略”检查实际遗漏，只在现有策略字段能覆盖时生成候选；没有缺口或超出当前能力边界会拒绝，不生成一个假装有提升的方案。可调depth默认值、require_counterevidence、require_gap_analysis；它不扩展成任意提示词/代码编辑器。

回放保留原输入、用户明确的研究深度、场景假设与时间边界，比较当前策略与候选的能力覆盖/节点数量和真实数学结果。输入按币种、单位、口径及季度数值去重，改公司标签/文件名不增加独立样本。至少3组不同输入；确定性保留组不许遗漏人工要求；数学摘要必须一致；至少一例需求覆盖改善或同覆盖下节点减少；不得有回归。预测不满足数据门槛不算能力已成功完成。

反向对照在生产执行与本地回放使用同一口径：没有人工标注为反向（contradicts）的资料时，保留已有支持/背景分组并明确缺口，不满足反向能力要求。存在反向标签只证明有此类资料，不证明有效反证、逻辑矛盾或事实正确性；没有另加“支持与反向必须同时存在”的门槛。needs_input 仅对已完成具体待补清单的 gaps 算覆盖，其他能力没有这种完成语义。

评估使用人工要求，不是LLM自评分。它检验本地规划覆盖与计算一致性，不衡量模型真确率、盈利能力或真实供应商稳定性。保留组是本地分组门禁，候选可能参考同一案例库，不能称为完全独立、盲测的外部验证。

候选、活动策略或去重后的验收案例集合变动，激活旧评估返回冲突。满足门槛后仍须人工确认激活；只影响新计划，旧授权计划作废，历史报告不重写。保留最多20次策略历史，可显式回滚。相同问题人工选择的concise/deep不会被策略默认值偷偷覆盖。

回放实现单独版本化；实现版本变化后，旧评估保留为历史结果，不能用于激活或回滚。原活动策略退回内置规则并说明版本原因，须重新回放并明确激活；这不表示用户撤回了授权，不改写原报告、评估、数学结果或输入快照。
