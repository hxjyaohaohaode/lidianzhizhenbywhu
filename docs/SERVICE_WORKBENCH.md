# 研究服务工作台：使用边界与验收合同

## 第一条真实工作链

首次注册无任何企业、报告或业务样本。先导入自己的 CSV/XLSX/JSON，检查单季或累计口径，在预览后确认。可在“身份与连接”建立经营、投资研究、行业研究、审阅等身份，分别设置目标、企业范围、研究深度、输出方式与外发预算。服务身份是同一账户的上下文镜头，不是组织权限或独立租户；不能通过切换身份获取别人的资料。

研究助手既有可伸缩侧栏，也有独立全宽工作区。会话与当前账户、身份、企业绑定，保存问题、实际工具结果、工具耗时与输入/输出摘要。默认本地读取不收费；没有把关键词路由或规则回复宣传成大模型。需要模型研判时，从会话提出研究提案，预览实际输入、历史问题范围、数据/身份版本与调用上限，再批准派发已有动态 Agent 执行器。结果归档后回到同一会话，保留报告、运行和跟进引用。

操作提案包含研究、行动、跟踪和记忆四种。预览不写业务对象；确认时再次核对数据与身份版本，重复确认不重复派发。改企业、撤回身份或删除上下文不会让旧提案继续执行。历史问题默认不外发；勾选后显示实际冻结内容，超出上限拒绝而不是静默截断。

## 可用性

导航按钮真实改变页面网格宽度，不只是隐藏文字。侧栏可独立收起；助手支持鼠标调整宽度和键盘调整。移动端改为抽屉、遮罩、焦点约束与 Escape 退出。账户/身份/企业变化时丢弃迟到响应；阅读、提交和模型运行是不同状态。输入草稿仅保留在当前页面内存，不落 localStorage。

原始 Logo 和开场视频保持原字节；支持跳过、减少动效、播放失败回退和手动重播。默认空页面不填充随机财务数值或演示报告。

## 模型连接与密钥

在“身份与连接”填写名称、兼容接口 HTTPS 地址、模型名和密钥，重新输入当前账户密码后保存。密钥通过本机独立 Fernet 主密钥加密；API、账户导出和日志不返回密钥或密文。私有连接只允许所属账户使用，连接版本改变会使旧授权计划失效；更改域名必须提交新密钥，防止旧密钥被转发到新站点。

连接限制公开网络地址、拒绝内网/DNS重绑定/重定向等链路。不能保证任意供应商兼容，仍需在自己的账户额度下执行真实授权任务验证。Fernet 不抵御已取得本机管理员权限且可读数据库及主密钥的攻击者。主密钥丢失时拒绝重新生成来掩盖解密失败。

会话管理列出登录会话和用户代理说明，允许撤销其他会话或当前会话。用户代理不是已认证设备身份。敏感操作要求再次验证密码，限制尝试频次与哈希并发。身份不授予任意代码执行、后台自动花费、交易或组织成员授权。

## 主动跟踪

用户显式创建指标、阈值、比较方向和身份/企业范围规则。应用运行时每60秒检查已保存的本地数据；关闭程序后不会继续监控，不自动访问付费模型，不假称实时行情。未取得输入、输入过期、阈值命中分别说明。按规则版本和财报修订去重，确认和归档警报不会立即重复刷出同一条提醒。可以从警报继续研究或建立行动。

跟踪表单与助手跟踪提案的四个比率指标以百分数填写（20 表示20%），两个金额指标始终用人民币元；展示偏好不改变输入单位。指标切换清空阈值并说明原因，取消不写入。规则、观测值、历史提醒和派生行动/助手上下文均展示明确单位；技术原始值单独保留。服务契约仍是比例小数和元，实际阈值界限仍为[-1e15,1e15]，不迁移历史记录或增加财务指标。

直接从企业数据新建行动或跟踪，必须提交 `source_ref.kind=dataset` 以及当时查看的 `dataset_version`、`dataset_hash`，缺失或不完整返回422；完整但已过期的引用返回409，企业不存在或不属于账户返回404。保存时在同一写事务内核对所属账户、身份范围、版本与内容指纹，不能自动换成最新修订；勾选保留历史也不能绕过直接数据引用的修订核对。报告、提醒、行动和助手原消息可使用其可核验的冻结来源。已有记录的精确提交标识重试只返回原结果，不新建记录；版本化跟踪编辑省略不可变来源，原始依据保持不变。无企业绑定的人工行动仍可创建，旧历史缺少依据时明确显示未知，不回填今天的数据。

## 安装、迁移与回滚

Windows 双击 start-windows.cmd。脚本探测能够实际运行的解释器，不盲目使用 py -3；检查项目 .venv 属于该目录，失败环境不会自动删除。首次安装前明确确认下载，依赖失败停止，不继续假启动。只在项目 .venv 安装，端口占用不结束其他进程。

本版 requirements.txt 采用独立核对过的修复版本约束；本机旧依赖域测试与 GitHub 修复依赖 CI 是不同证据。启动环境检查必须匹配当前约束，不应绕过。

替换源码前关闭原服务并备份完整项目，特别保留 .runtime、.env、.git 和自己的其他资料。数据库版本升为3，旧程序拒绝降级写入。旧 .venv 可以重新建立，但不是业务数据库；没有备份不要删除运行目录。

备份命令：`python scripts/backup.py --help`。有私有连接的数据库备份依赖原来的 credentials.key；使用 --include-key 时在独立文件中复制匹配主密钥，不能把数据库和主密钥同时上传公开仓库。恢复操作应在副本验证账户、数据、历史任务和私有连接解密，再替换正式运行目录。
