# 取消、外发边界与实时读取的一致性

日期：2026-10-01 UTC。基线为 `b79824a`；本轮保留原供应商、财务公式、历史报告、品牌文件及数据库 schema。没有引入业务演示数据、自动付费重试或新外发目的地。

## 复现的根因与修复合同

| 根因 | 基线复现 | 本轮合同与同类检查 |
|---|---|---|
| 将异步等待结束当成底层请求结束 | DNS 尚未返回时取消任务，取消已完成后，原后台线程仍开始 HTTP POST | 同一个截止/取消控制贯穿 DNS 返回、TCP 建连、TLS 握手、HTTP 头及请求体发送；取消中断已登记的 socket，迟到 DNS/连接不能重新开始 HTTP |
| 并发限制只数等待中的任务 | 取消释放运行槽位，但原 DNS/读取线程可能还活着 | 模型服务最多保留 8 个未结束传输线程；槽位由实际线程退出释放，取消和超时不能提前释放。容量满明确拒绝，不排无界队列、不自动重试 |
| 授权检查与真正外发之间还有阻塞阶段 | 已批准请求进入 DNS 后撤回身份或模型连接，旧检查无法代表即将发送时的权限 | 新旧批准执行器均给每次调用复制独立配置，DNS/TLS 之后、HTTP 发送前重新核对当前账户、来源与批准指纹。回调异常按撤权处理；可能已发送头/体后只记录未知结果 |
| 存储整数未约束到端到端可表达范围 | `after/offset=2^63` 导致读取 500，SSE 已返回 200 后在 SQL 绑定处中断，正文为空 | 游标、修订及乐观版本统一限制到 JavaScript 可精确表示且 SQLite 可绑定的整数范围。续读头只接受有界 ASCII 十进制；非法输入在流式响应开始前返回 422 |
| 实时读取的销毁只拦成功分支 | 已销毁或身份切换后的网络错误仍更新标签；迟到 SSE 回调也能修改页面，记录删除后无限轮询 | 统一活动/上下文门槛覆盖成功、失败和 SSE 回调；重复 start 不新建订阅；403/404 停止读取，格式坏的事件改为只读轮询，终态竞争仍补读 |

## 外发与恢复的准确边界

- 取消不能撤回已经送到供应商的字节，也不能证明供应商未处理或未计费。发送之后的取消、超时和连接故障仍是未知远端结果，保留原台账且恢复不自动重发。
- 操作系统 DNS 调用不能被 Python 安全强杀。本轮保证迟到解析不继续发送，并把尚未返回的解析保留在容量限制内；不声称能让挂起的操作系统解析立即结束。持续占满时先排查主机 DNS/网络，应用不会以更多线程补偿。
- 本地授权变化与传输容量不足不是供应商故障，不打开其他账户共享的供应商熔断器。明确未发送的调用预约仍占用原批准预算；不把预算释放解释成账单退款。报告不会把这些预约的记忆/证据列为已外发。
- 回调失败不公开数据库或凭据异常文本。每次调用的回调不会写回共享供应商配置；私有连接保持账户隔离。
- 财务金额合同不变；新整数上界只用于游标、修订和版本输入。数据库没有重建/迁移，历史报告没有重算。

## 验收入口

- `tests/test_transport_lifecycle.py`：真实 ProviderService 的线程生命周期，隔离 DNS/socket 替身；取消/超时、待执行线程、迟到连接、TLS/响应等待、逐次发送授权、容量保持与释放，以及本地拒绝不污染供应商熔断
- `tests/test_execution_services.py`：实际账户、身份和私有连接，在新旧批准执行器 DNS 阶段撤权、旋转/删除连接；取消/关闭与显式恢复不重复未知预约
- `tests/test_input_integer_bounds.py`：游标/续读头/修订/版本正文及嵌套批量版本的合法上界和超界拒绝；普通续读顺序与终态保持
- `tests/frontend.test.mjs`：销毁后错误/所有 SSE 回调、身份切换、重复启动、403/404 以及非法事件游标；原终态竞争测试保留
- `scripts/full_chain_check.py`：运行中的真实 Uvicorn 对超界同步/分页/修订/续读头提前返回 JSON 422；合法最大游标返回 SSE 终态，并继续执行原重启/备份旅程
