# 锂电智诊：自主协同与交互升级交付报告

## 实际交付

本轮以先前“深度升级交付包”为源码基线，保留其数据、身份、数学计算、证据、记忆、报告与行动业务，新增自主协同和策略治理实现。工作区从11个增加为12个。生产初始业务数据仍为零，没有样例自动载入、随机图表、模拟模型回复或虚假预测置信度。

### 执行器不再是固定顺序

16项注册能力（11项本地工具、5项可选模型职责），按目标、深度、当前输入质量、显式假设和策略编译真实依赖图；任务只选择必要能力。可选模型规划在限定合同内调整专家分工、并行/先证据/先解释顺序、只读工具选择；数据或证据缺口可追加本地核查，结构门禁失败最多2轮修订。纯重复解释本地去重，不多花调用费用。

模型可分角色绑定服务端已配置供应商，累计最多8次外部尝试与明确字符预算；含规划、候补和修订。仅预先批准候补且明确HTTP429时才尝试候补；超时、连接失败、崩溃时外部结果不明则不自动重复发请求。实际外发内容、引用和记忆ID、供应商与usage留有记录。不同角色同一模型不冒充独立共识。

运行可安全暂停、显式继续或取消；图、断点、调用台账持久化。恢复前验证输入/产物/事件摘要，完成节点复用，未知外部调用不重做。取消禁止迟到结果写回。模型不能修改代码、增加任意工具或URL、绕过授权、直接写业务数据库或交易。

### 数学建模进入同一协同链

预测、固定/变动成本情景、反向证据和数据缺口共享冻结输入，真实计算产物进入专家上下文与最终报告。预测目标可选收入/成本/现金流/毛利率、1–4步；情景需明确假设，不能从模型文字猜参数。数据不足保留blocked原因。

预测在原滚动回测之外新增“开发折选方法→锁定→末两期留出”，至少10个已结束连续季度；改变留出真实值不能影响开发选择和第一留出预测。与最近值基线分别比较；小样本同序列验证不是外部行业验证、金融准确性认证或置信度。

### 演进有实际案例、门槛和回滚

报告人工验收分别记录预期能力、说明和是否同意本地回放。“从验收提出策略”根据真实遗漏生成允许范围的候选，并实际本地回放；不付费调模型、不用模型自评分。按财务内容去重，改名/重复报告不增加独立案例；至少3份不同输入、保留组需求不缺失、数学不回归、有实际改善才允许人工激活。

回放保留用户原有显式深度与假设；候选、基线或验收案例集合改变后旧评估不能激活。策略只影响新计划，可回滚，不改变旧报告、数学公式、模型权重或程序。它是受治理的本地规划改进，不宣传无人值守全面自进化。

### 原始品牌与真实交互

比赛工程原Logo与5.04秒MP4原字节恢复，SHA256一致；新路径与旧资源别名、视频Range请求均验证。开场可跳过、Escape退出、重播，减少动效/播放失败/最长等待均有回退，不阻塞登录。

真实DAG支持图/清单、缩放、键盘节点详情、依赖/权限/产物检查，展示实际图重排、断点和外发计数。运行优先SSE，失败只读轮询有界退避；任务终态与在途请求竞争会补读，跨接口读到新旧状态会重新取一致报告，切页/换账户丢弃迟到响应。移动抽屉、主题、焦点和未保存草稿保持。

## 明确边界

上述真实HTTP/SSE是协议端到端，不等于浏览器Cookie/SameSite/CSP/模块加载端到端；原生导航错误保留，DOM桥接不冒充原生成功。真实外部模型和搜索供应商调用次数为0，供应商测试为显式注入，不代表账号/额度或真实模型表现通过。

未完成Windows/macOS实机、Docker、公网HTTPS、长期高负载、分布式运行、全量依赖漏洞联网审计、可选PDF修复版安装联调、专业预测经验校准、获奖TypeScript库无损迁移。此次没有向GitHub提交代码或覆盖main。当前形式为可运行源码ZIP，不是生产安全认证或软件著作权审批承诺。

## 使用

解压lidian-workbench，创建Python虚拟环境，安装requirements.txt，运行scripts/start.py。已含编译前端，无需先安装Node.js；README有Windows命令。首次注册为零数据，导入自己的数据；测试样本只在tests及隔离验收内。原数据库先备份，在副本迁移，勿直接覆盖比赛原工程运行库。

## 最终文件核验

release-manifest.json记录每个打包文件的大小与SHA256（不包含清单自身）。包外“交付复验.json”记录最终ZIP重新解压、清单核对、后端/前端复跑、编译一致性与真实HTTP链结果，以其actual_completed为准；不把打包前通过冒充包后已通过。
