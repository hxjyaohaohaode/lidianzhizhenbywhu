# 企业对照的保存、批准与历史来源

## 这次补齐的实际缺口

上一轮已经把原实验、报告、行动和跟踪接通，但“企业对照”仍只显示一次请求的临时结果。用户不能将已经核对的共同季度比较作为可复核输入交给 Agent；重新描述同行数字也无法保证企业、版本与口径一致。

本次沿用现有财务计算，不引入行业样本或新公式。目标是一条明确可审阅的路径：选择本人数据 → 核对共同季度和可比性 → 保存对照 → 选择主企业并预览 Agent 计划 → 明确批准新增的企业输入 → 报告保留原对照 → 同行修订或来源清理后提示当前适用性变化。

## 数据与授权合同

- 每份对照保存 2–8 个不同数据集的完整原始快照、ID、版本和内容哈希。相同企业可以有不同口径数据集，不按企业名偷偷合并；重复数据集不能冒充多个样本。
- 目标季度必须在所有成员中存在；比较模式、归一化货币/数量单位、单季口径、计算日期与用户说明明确保存。没有基期或缺少字段时保留原计算的空值和限制，不补造同行指标。
- 对照是账户所有、身份绑定的独立记录。新计划只接受用户明确选中的记录 ID、版本及哈希；主企业必须是成员，目标季度和比较方式必须一致，同时选择数学实验时两者期间也须一致。
- 预览、批准与每次外发重新核对所有成员的所有权、身份范围及版本，不仅检查主企业。失效的对照可保留历史阅读，不能悄悄用最新数据替换后继续执行。
- 外发批准说明列出额外企业及对照范围。模型只获得受上下文预算限制的指标投影、可比性说明和可验证引用，不自动获取同行记忆或证据。同行数字的引用含成员标识，不冒充主企业指标；超预算省略的内容不得继续保留可引用权限。
- 报告、导出与本地回放保留原冻结对照。对照记录或同行数据更新/删除，只改变当前影响提示，并传播给报告派生的行动；不重算、不重写历史报告，也不把重复比较次数当独立财务样本。

## 与用户手册的对应

| 用户动作 | 说明入口 | 核查重点 |
|---|---|---|
| 临时查看企业对照 | 用户手册“企业对照与后续研判” | 用户样本、共同季度、不是行业排名 |
| 保存已核对的对照 | 同上 | 成员版本、可比性说明、原始结果 |
| 交给 Agent | “协同研判”与“带着原始依据继续工作” | 主企业、目标期间、额外输入、明确批准 |
| 报告转行动 | “报告与行动” | 原对照来源及同行变化提示 |
| 修订、清理与恢复 | “同步、导出和清理”、部署与恢复手册 | 原报告不变；恢复需要数据库备份及配对密钥 |
