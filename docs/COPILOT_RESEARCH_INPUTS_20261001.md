# 助手连续研究与已保存数学输入

日期：2026-10-01 UTC。基线远端 `da2613b4f6b4b751c3cd5890f3a6cac7fd2ad8e1`，其完整树与本地 `c7395e9` 一致。此轮修改生产链路；保留财务公式、四家模型配置、原品牌字节及历史报告，不迁移数据库或生成运行时演示数据。

## 实际复现的断点

1. 本地回答保持了历史季度，但把“继续展开刚才的原因”交给 Agent 后，计划无阻断地改成最新季度与同比。最近两轮原问题没有指标时，后续追问还会丢失已解析范围。
2. 主 Agent 支持保存实验/对照，助手提案合同和界面却无法引用它们。聊天内也未呈现归档数学产物，只检查主企业版本，看不到同行修订导致的当前适用性变化。
3. 首轮独立复核发现纯“那同比呢”会被收入增速关键词抢占；真实 HTTP 和新增测试发现短追问虽可回答，却被提案最少五字拦截。生产路径与前端约束一起修复，未放宽无来源的短目标。

## 实现合同

- 只对有界继续表达继承紧邻上一条成功解析的范围，不拼接任意历史原文。明确的最新期、指标、季度、基期及无法识别/歧义请求保持各自行为；不是通用语言理解。
- 同账户、同会话的来源回答仅在目标未改写时提供规范化季度/基期/指标。规范化文字在批准页可见；完整历史仍由独立选择控制。与实验/对照的季度、日期或假设冲突不偷偷覆盖。
- 助手只传显式选中的 ID/版本/哈希，复用主计划的冻结、归属、身份、所有成员当前版本、原计算复验、外发范围和预算门禁。非研究提案携带这些引用在合同入口被拒绝。
- 预测实验选择时锁定并省略对应本次预测参数；取消选择恢复未提交值。加载和提交受会话/身份/企业/弹窗及输入变化保护，旧响应不能盖掉新草稿。
- 批准页展示原实验假设与全部对照成员；同会话直接呈现保存的数学结果、单位及边界。来源变化仅增加适用性提示，历史结果不重算。
