# 异常、恢复与不确定结果

|情况|程序实际处理|使用者应采取的动作|
|---|---|---|
|零业务数据|显示空工作区，不生成公司、图表或概率|导入自己可核验的数据|
|缺少可选财务字段|保留缺失，必要时追加缺口节点；规则覆盖不足不评分|补充同口径原报表并保存新修订|
|预测样本/期间不满足|留下blocked与原因，不画虚假预测区间|检查已结束连续季度或改为情景分析|
|无反向资料|保留资料缺口，不制造反驳证据|人工搜集后审阅，再建计划|
|模型未配置|计划阻塞或改本地模式，不模拟回答|配置自己账户真实可用模型后重新预览|
|规划输出非法|记录失败，使用已批准本地依赖图继续|查看规划产物，必要时新计划|
|解释引用非法|拒绝非法解释，原预算内有限修订；纯重复本地去重|未解决的结论保持待核查|
|次数/字符预算用尽|停止后续付费派发，保留已有结果|检查台账，必要时明确新授权|
|HTTP429|只在已选候补与原累计预算内降级|没有候补则本地受限完成|
|超时/连接错误|不自动重发；可能已在供应商侧产生费用|先检查供应商账单，再决定新任务|
|点击暂停|进入pause_requested，批次结束后paused|等待安全边界；已发请求不能撤回|
|取消|禁止后续任务与晚到产物写回，保留已发生的调用记录|必要时新建任务，而非恢复取消|
|进程强制退出|启动识别未结束运行，保留图与断点|在执行详情显式继续；未知外部请求不重发|
|断点或产物哈希不一致|fail closed，不把坏产物当可用缓存|保留证据并从可信备份检查，不手动修哈希|
|证据/记忆撤回或数据/模型改变|下一次外发被拒；历史冻结报告不改|创建新计划，核对新的外发范围|
|实时事件连接故障|提示降级，只读轮询1.5秒起退避至12秒|不必重新点击执行；写入永不自动重试|
|终止事件与请求竞争|合并末次补读，不丢弃终态|查看真实已完成/受限/失败标识|
|断网/切换账户|保留草稿；旧身份迟到响应被丢弃|先确认服务器状态，不重复导入或付款|
|开场不自动播放/解码错误|静态原Logo、跳过、Escape、最长等待回退|直接进入应用；减少动效或关闭后重播|
|并发写入/控制冲突|返回版本冲突，不暗覆写|重新读取后明确决定|
|策略样本不足/评估过期|禁止激活，显示具体门槛|补真实验收记录或重新回放；不复制输入凑数|
|完整依赖审计或公网验收缺失|交付报告明确未验收|不把本机通过当公网放行证明|

SQLite备份使用scripts/backup.py在线一致性备份，不直接只拷贝活动主库。恢复到独立目录，避免混入旧WAL/SHM；启动后先核对账户、数据修订、任务快照再切换使用。备份含敏感信息，不进入公开ZIP。

## 恢复前的一致性门槛

启动先检查基础、工作区及自主编排版本，再以单一事务迁移。未知更高版本、外键孤立或迁移失败不会留下部分业务升级；保留原库，先查可信备份，勿手工改版本号。

历史修订使用/恢复会核对内容哈希、数据结构及标准金额单位。坏记录仍列出元数据和明确警告，但不计算其差异或提供恢复入口；其他已校验修订仍可查看。不一致内容拒绝使用，不修复哈希掩盖问题。成功恢复仍创建新修订，并在审计中记录来源修订；旧报告内容保持不变。

备份同时检查 SQLite 页面结构和外键，并拒绝目标旁的既有 WAL、SHM、journal 或回执文件。回执成功不是可直接上线的证明，应在全新 DATA_DIR 按部署手册核对登录、所有权、修订、报告及匹配密钥。数据库副本缺少可用主密钥时，批准任务仅保留本地报告并明确提示未外发；不要生成新密钥冒充原密钥。

删除证据或会话时，对应的当前审阅/验收子记录一起清理；冻结报告、独立行动验收和审计历史不变。旧版遗留孤立子记录保留在账户导出，不再占当前记录额度。范围与实际故障回归见[恢复一致性记录](RECOVERY_INTEGRITY_20260930.md)。

## 取消与传输仍未结束时

取消/超时会中断已登记的模型连接；尚未返回的 DNS 结果到达后不能继续开始 HTTP。操作系统解析不能安全强杀，因此未结束传输仍占容量，最多 8 个；满额时明确拒绝新尝试，不用更多线程或自动重发掩盖问题。已经发送的请求仍可能被计费，未知结果不能靠恢复重新派发。

身份、来源或连接在 DNS/TLS 阶段改变时，发送前再次检查；明确未发送的预约不列为资料已外发，也不会把本地撤权当供应商故障。实时记录被删除/撤权后停止读取，旧页面的迟到失败不改新页面。具体同类故障与验证边界见[执行一致性记录](EXECUTION_RESILIENCE_20261001.md)。
