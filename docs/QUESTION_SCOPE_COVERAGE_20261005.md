# 问题指标与预测范围保持（2026-10-05）

## 用户可见问题与修正

研究助手原先独立从少数中文片段选择预测指标，未使用已经解析的问题范围。
例如 `forecast cost` 的事实答复是营业成本，预测卡却成功给出营业收入预测；
`预测净利润` 和 `资产负债率预测` 也会错误地回退到收入预测。
修正后，只有已注册的营业收入、营业成本、经营现金流和毛利率能够进行单指标预测。
中文及英文别名沿用现有解析结果，不支持或同时包含多个预测指标时明确说明并返回
受限工具回执，不调用通用预测计算器，也不以其他指标替代。

现金流事实原本自动附带经营现金收入比；这个伴随事实不代表用户要求第二项预测。
正常现金流预测继续成立；明确同时询问现金收入比等第二个指标时，仍要求用户单独
指定受支持指标。原数学公式、预测算法、历史连续性、样本量、缺失值和季度范围门槛不变。

另一个问题是研究深度截断了用户明确要求的指标。简洁模式四指标问题会遗漏净利润，
均衡模式七指标问题会遗漏总资产周转率，保存的范围却仍包含它们；工作区助手也会
在七指标历史问题中只返回五项。修正后，两条入口都保留现有有限指标目录中全部
明确请求的事实、答复及适用血缘。原默认概览指标保持；深度继续限制证据、趋势长度
及补充发现，不再静默改变已请求或已继承的问题范围。缺失值明确保留为不可计算，
不会填零补齐。

## 未成立的相邻审查假设

同轮核查还检查了“选中数学实验但省略 execution 会进入旧执行路径”的假设。
当前真实 API 会为选中的实验补齐声明式执行选项。情景/预测实验分别以省略、null、
空对象三种输入创建的六个计划都走现有新执行路径；批准后撤回实验，实际工作器在
供应商测试探针之前拒绝派发，冻结历史保留。有效实验和真正无实验的旧计划控制
仍能到达具名探针。此假设未被证实为当前 API 漏洞，未为追求审查通过而制造一个
不受支持的重写历史计划。探针不是实际外部服务验证。
