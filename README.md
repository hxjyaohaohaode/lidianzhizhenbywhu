# 锂电智诊

面向锂电企业经营研究的工作台：数学建模、动态 Agent 协同和可审阅的策略演进是基础，研究助手、数据、证据、报告、行动与跟踪围绕同一条真实数据链工作。

保留比赛工程原始 Logo 和开场动画。首次工作区为空，没有自动生成的企业财报、模拟模型回复或无来源概率。

## Windows 启动

解压完整发布包，双击 **start-windows.cmd**。它检查可运行的 Python、项目虚拟环境、依赖与编译前端；首次下载依赖需要输入 y 确认。无需管理员权限，不修改系统执行策略，不结束占用端口的其他进程。

针对本机目录，在 PowerShell 中也可执行：

```powershell
cd "D:\项目文件\比赛文件\计算机设计大赛\lidian-workbench"
.\start-windows.cmd
```

脚本不会继续依赖已失效的 Python314 启动器路径。若没有可用解释器，需要先安装官方 Python 3.13；3.11–3.14 是探测范围，不代表每个版本均已完成验收。损坏 .venv 不自动删除，错误提示会保留原因。程序地址通常为 `http://127.0.0.1:8000`。

## 第一次使用

1. 注册自己的账户，导入自己的企业数据，核对单季/累计口径后确认入库。
2. 在“身份与连接”设置工作身份和企业范围；要使用外部模型，再保存私有模型连接。
3. 在研究助手中提出问题，查看实际工具结果；需要进一步研判时预览并批准计划，之后从同一会话查看报告、建立行动或设置跟踪。

无密钥仍可使用本地数据核验、检索、数学工具和报告，但不伪装成已调用大模型。模型兼容性、实际额度及第三方网络需要在自己的账户下验证。

## 三个基础模块

- **Agent 协同**：目标与输入驱动的依赖图、工具合同、按角色选择模型、冻结上下文、外发预算、可追溯产物、暂停/继续/取消和有限修订。模型不能修改程序或直接写业务库。
- **数学建模**：统一财务口径、DQI/GMPS透明研究规则、成本情景/敏感性、四类预测基线与开发/留出验证。保留缺失值和不适用原因，不宣称专业预测经验校准已完成。
- **策略演进**：用户验收形成案例，去重回放比较，明确基线、门槛和人工批准，支持回滚；不把模型自评分当效果验证。

## 更新与备份

先关闭旧服务并备份，不要删除或覆盖自己的 `.runtime`、`.env`、`.git` 或资料。基础数据库版本仍为3，跨工作区来源合同升级工作区扩展版本至3，旧应用会拒绝降级写入。升级不会重算或重写历史报告；高于支持版本的数据库拒绝降级写入。私有连接的恢复需要数据库与原匹配主密钥；不要把两者上传 GitHub。备份帮助：`python scripts/backup.py --help`。

## 开发与验收

```sh
python -m pip install -r requirements-dev.txt
npm ci --ignore-scripts
npm run build
python scripts/verify.py --full-chain
python -m playwright install chromium
python scripts/native_acceptance.py
```

`verify.py` 执行后端、前端、编译与限定源码检查；`--full-chain` 另启临时数据库和实际Uvicorn进程验证HTTP/SSE/重启恢复。原生验收不改变浏览器策略、不开传输桥接；只有实际通过才能算原生浏览器链路。首次源码克隆如缺少编译文件需先构建，完整发布ZIP已包含编译JS。
