# 锂电智诊 · 企业经营研究工作台

面向锂电企业经营与财务研究，连接**真实输入、可审阅计划、协同执行、证据复核和行动验收**。不是电池硬件检测，不内置真实企业行情，不承诺预测准确率。

## 直接运行

GitHub 源码需要先编译前端；独立发布包若已包含 `web/dist` 则可跳过前两行。安装 Node.js 22+ 与 Python 3.11+，在项目文件夹打开 PowerShell：

```powershell
npm ci --ignore-scripts
npm run build
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe scripts/start.py
```

浏览器打开 `http://127.0.0.1:8000`，注册独立账户。以后双击 `start-windows.cmd`。不需要修改 PowerShell 执行策略。端口占用时加 `--port 8001`，再打开对应端口。Linux/macOS 使用 `.venv/bin/python`。

**首次工作区完全为空，不再提供生成演示财报的按钮。** 输入你自己的数据；CSV 空模板在 `examples/financial-template.csv`。`tests/fixtures` 及浏览器验收使用明确标记的合成数据，只用于测试，服务不会自动载入。不要把测试截图当成真实公司分析结果。

## 完整业务闭环

1. **经营数据**：手工录入或上传 CSV/XLSX/JSON → 选择单季或年内累计 → 核对单位、缺项、异常和差异 → 明确提交。预览不写入财务库，实际入库为事务操作。修改、恢复均新增修订，不覆盖旧报告。
2. **证据资料**：保存原文或可信白名单网页 → 确认企业范围、日期、标签、支持/反向立场及人工审阅状态 → 在该范围内检索。人工接受不等于系统认证；被排除或过期的资料不进入新计划。
3. **偏好与设置 / 长期记忆**：按企业设置目标和关注方向；记忆必须批准、满足范围与有效期才纳入。偏好影响服务重点，不调整财务计算结果。
4. **协同研判**：填写研究问题、验收标准、模型预算和可选历史 → 生成执行计划 → 展开节点、上下文和授权边界 → 批准后执行。过期或基础数据改变的计划不能直接执行。
5. **研判报告**：查看计算、模型解释、来源、实际发送的上下文、节点产物、哈希一致性和错误。人工审阅模型解释单独保存，不暗改原报告。
6. **跟进行动**：将核查或报告转为行动，记录负责人、期限、验收标准；通过状态机推进，完成时提交说明和证据。
7. **情景与预测 / 企业对照**：固定与变动成本情景、二维敏感性、四种透明时间序列基线的滚动回测；选择真实数据、写明假设并保存冻结实验。跨企业比较使用共同季度。

12 个工作区：工作简报、协同研判、经营数据、证据资料、情景与预测、企业对照、研判报告、跟进行动、长期记忆、策略实验室、执行记录、偏好与设置。桌面导航可收缩；研究助手按当前企业展示原始字段、计算公式、季度轨迹、数据修订、质量警告及有企业范围的资料候选，并导向真实操作。企业经营、投资研究、财务分析和顾问服务是同一账户内可切换的研究视角，影响追问与已批准记忆的适用范围，**不提供额外数据权限，也不冒充已调用的大模型聊天**。

## 自主协同、数学建模与受控演进

执行器按问题、研究深度、已批准假设、数据质量与有效策略生成真实依赖图。目录有16项注册能力，其中11项为本地工具，5项为可选模型职责；一次任务只选择必要节点，不等于16个模型。数据核验、量化、证据、上下文、结构复核、复盘和报告是基础；反向证据、缺口、预测、情景与专家分工按需加入。

模型规划默认关闭。开启后，模型可在已披露范围选择研究重点、增减可选专家、选择并行/先证据/先量化解释，并请求冻结数据上的只读工具。严格合同与图校验拒绝未知工具、环、脚本、SQL、URL、额外权限。模型不改源代码、数据库业务记录或财务公式。不同职责可选不同已配置供应商；同一模型扮演多角色不构成独立共识。

外部调用累计上限由用户选择，最多8次，含规划、专家、修订和候补尝试；引用/结构失败最多追加2轮修订，完全重复的解释本地去重，不多付费重写。任务累计字符预算与单次18,000字符预算分别检查，字符不是token或金额。只有供应商实际返回的usage才记录token；不是成本承诺。

暂停在安全批次边界完成。已完成节点按输入/产物/事件哈希复用；重启后显式继续；未完成的外部请求结果未知时不自动重发。默认不跨供应商降级；只有用户预先勾选候补且主服务明确返回HTTP429时，才在同一预算内尝试候补。超时或结果不明不自动重试。取消不等于远端请求能够撤回。

“策略实验室”从用户明确授权的真实报告验收中找遗漏，自动提出有限的本地规划策略，再与当前策略逐例回放。按财务输入内容去重，至少3份不同输入，保留组不能漏掉人工要求，数学结果不能回归，必须出现改善才允许人工激活。评估案例、候选或基线变化会阻止旧评估激活；支持回滚。它不训练模型权重、不自动部署代码、不以模型给自己的分数冒充质量证明。

原始Logo和5.04秒开场视频从比赛工程按字节恢复。支持跳过、Escape、故障静态回退、最长等待、减少动效与重播；开场不读取模型或阻塞登录。

完整协议：`docs/AUTONOMY.md`；异常恢复：`docs/RECOVERY.md`；测试映射：`docs/TEST_MATRIX.md`。

## 服务端模型与搜索配置

内置 DeepSeek、Qwen、GLM 固定官方接口适配；模型名称可通过环境变量指定。默认名称不是“最新/最优模型”声明，需以自己账户可用模型为准。

`.env.example`只是配置说明，**不会自动读取 `.env` 文件**。例如：

```powershell
$env:DEEPSEEK_API_KEY = "在本机填写自己的密钥"
$env:DEEPSEEK_MODEL = "账户实际可用的模型ID"
# 搜索是独立可选服务，只有用户勾选同意并提交查询时调用。
$env:TAVILY_API_KEY = "可选搜索密钥"
.\.venv\Scripts\python.exe scripts/start.py
```

不向聊天、Git或浏览器提交密钥。已配置不代表账号、额度或网络已通过验证。搜索结果只作待审阅候选，确认后入库；不是全市场自动采集服务。

## 部署与隐私边界

默认只监听本机、单进程SQLite。运行数据位于 `.runtime/workbench`；不要将它提交Git或与源码一起公开。旧V3工作台数据库可在备份后的副本上执行新增表/触发器迁移；原获奖TypeScript版本数据库**不兼容**，不能直接覆盖或自动导入旧密钥。

已在 Windows 实机验证独立 Uvicorn 进程上的本机 HTTP/SSE、暂停后强制终止与重启恢复、数据库备份，以及原生 Chromium 的网络、Cookie、CSP 与完整业务界面流程。真实外部供应商、Docker、公网 HTTPS、多天负载和完整联网依赖漏洞审计尚未验证。默认 PDF 解析关闭；可选解析器需单独安装、审计与验收。不要把本地功能验收当作公网生产安全认证。

手册 `docs/USER_MANUAL.md`；实现与数据合同 `docs/ARCHITECTURE.md`；方法 `docs/METHODS.md`；安全 `SECURITY.md`；部署/备份 `docs/DEPLOY.md`；实际升级差异 `docs/FEATURE_MATRIX.md`；技术材料 `docs/COPYRIGHT_PREPARATION.md`。启动后 `/api/docs` 为同源接口文档，`/api/openapi.json` 为运行时合同。
